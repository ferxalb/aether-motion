# AETHER Motion

Write HTML. Render video. No browser.

```bash
npx @aether-motion/cli init my-video
cd my-video
npx @aether-motion/cli preview
npx @aether-motion/cli render
```

Works the same with `pnpm dlx`, `yarn dlx`, and `bunx`. Install globally (`npm i -g @aether-motion/cli`) to get the short `aether-motion` command.

`init` creates a sample project, installs the AETHER Motion Agent Skills, and registers the MCP server for your coding agent. Documentation: <https://github.com/ferxalb/aether-motion>
