# AETHER Motion composition contract

This is a portable summary for authoring compositions. In the repository, `AGENTS.md` is authoritative and contains the full supported property and attribute list.

## Root and clips

The composition root declares `data-composition-id`, `data-width`, `data-height`, and `data-duration` on the root element or through supported `<meta>` declarations. A timed visual uses `class="clip"`, `data-start`, `data-duration`, and `data-track-index`. Starts may be seconds or another clip's ID with an optional `+` or `-` offset. Use IDs to make dependencies readable.

```html
<div
  id="stage"
  data-composition-id="launch"
  data-width="1920"
  data-height="1080"
  data-duration="4"
  style="position: relative; background: #101522"
>
  <div
    id="title"
    class="clip"
    data-start="0"
    data-duration="4"
    data-track-index="0"
    style="position: absolute; left: 160px; top: 360px; width: 1600px; height: 200px;
              display: flex; align-items: center; justify-content: center;
              color: white; font-size: 96px; font-weight: bold"
  >
    Product launch
  </div>
</div>
```

Use supported elements (`div`, text, local PNG, JPEG, WebP, or SVG images, and inline static `<svg>`), inline styles or type/class/ID selectors, and documented CSS properties only. Layout dimensions accept pixels or percentages. Flex layout is available for centered and grouped content; do not rely on full browser layout behavior. Text can mix styles inline: `<span>`, `<strong>`, `<b>`, `<em>`, `<i>`, and `<code>` inside an element with its own text change color, weight, style, family, letter spacing, fill, or stroke, and fill with a gradient through `background` plus `background-clip: text`; `-webkit-text-stroke` with `color: transparent` gives outline type. Inline runs cannot be boxes (no padding, size, or `font-size`); see `examples/rich-text.html`. `font-style: italic` slants the embedded font when no italic face is installed. For display type, set `font-kerning: normal` on the text element to apply the font's pair kerning (the default `auto` does not kern). `data-hf-split` accepts `<br>` for multi-line kinetic text, and `data-hf-split-wrap` wraps lines at the element's width (give it a `width` or `max-width`) without changing the pieces' timing. Combine piece start values with `data-hf-split-x`, `-y`, `-scale`, `-rotate`, and `-opacity`, choose `data-hf-split-order` (`forward`, `reverse`, `center`, `edges`), clip with `data-hf-split-mask="words|lines"`, and animate lines with `data-hf-split-line-y`, `-line-opacity`, `-line-stagger`, and the other `-line-*` options; `spring(overshoot, oscillations)` is a settle-on-target easing for pieces and keyframes. See `examples/kinetic-wrap.html`.

## Templates

To render one composition with different text, colors, sizes, or assets, declare typed variables on `<html>` or the root: `data-composition-variables='[{"id":"title","type":"string","label":"Title","default":"Launch day"},{"id":"accent","type":"color","label":"Accent","default":"#4be0b8"}]'` (types `string`, `number`, `color`, `boolean`, `enum`, `image`, `font`; `id`, `type`, `label`, and a typed `default` are required). Use them with `var(--accent)` in CSS (set on the root, over `:root` declarations; a number with `unit: "px"` arrives as `48px`), `data-var-text="title"` (the element's own text; child elements stay), `data-var-src="logo"` (on `img`, `video`, `audio`, `source`), and `data-var-if="showBadge"`, `"!showBadge"`, or `"layout=left"` (removes the element, or a `<style>`, when false). Values are passed per render as a JSON object (`--variables`, `--variables-file`, `aether.json` `"variables"`, or the MCP `variables` argument). Every mistake is an explicit error. Check and snapshot each value set. See `examples/variables.html`.

## Deterministic motion

Use the native motion attributes for keyframes, camera moves, split text, reveals, counters, captions (`data-hf-captions` with a local `.json`, `.srt`, or `.vtt` transcript; times are seconds from the clip start; see AGENTS.md for options), and scene transitions. Keyframe times are seconds relative to the element's resolved start and must increase strictly within the clip duration. Keep all animation seekable from time alone: no `<script>`, timers, network, `Date.now()`, or unseeded randomness.

For finish, use `filter` on an element, functions applied in the order written with at most one `blur()` and one `drop-shadow()` (for example `filter: saturate(1.2) drop-shadow(0 12px 24px rgba(0,0,0,.5))`), color functions alone on the root to grade every frame, `mix-blend-mode` (every separable and non-separable mode, such as `multiply`, `screen`, `color`, and `luminosity`, plus `plus-lighter`, not inside `overflow: hidden`, rotated, revealed, filtered, or blended ancestors), and `data-motion-blur="on"` on the root for shutter motion blur (`data-motion-blur-shutter` in degrees, default 180; `data-motion-blur-samples="8"` for fast drafts). To blur only one fast element over a sharp background, put `data-hf-motion-blur="on"` on it instead (same `-shutter` and `-samples` options; not together with the root's, not nested, not on the root; stills from `--frame N --fps F` match the export at `F`); see `examples/layer-motion-blur.html`. For a localized glow, `data-hf-bloom="<intensity>"` with `data-hf-bloom-threshold`, `-radius`, and `-tint` adds a halo of the element's bright pixels while keeping it sharp, and `bloom` in `data-hf-keyframes` animates the intensity; see `examples/bloom.html`. Filter amounts animate in `data-hf-keyframes` (`blur`, `brightness`, `contrast`, `saturate`, `grayscale`, `sepia`, `hueRotate`, `invert`, `filterOpacity`, absolute values, and `dropShadow` as a `drop-shadow()` string) and in CSS `@keyframes` `filter`, for focus-ins, color reveals, and flashes; `glitch` (0 to 1) and `rgbSplit` (px) in `data-hf-keyframes` add digital glitch accents. Scene transitions include `crossfade`, `push-*`, `cover-*`, `wipe-*`, `whip-*`, `zoom-in`, `zoom-out`, `dip-to-black`, `dip-to-white`, `flash`, `blur`, `glitch`, and `rgb-split`; see `examples/light-transitions.html`. Cut elements to shapes with `clip-path` (`inset()`, `circle()`, `ellipse()`, `polygon()` in px or %, `path()`, and box keywords such as `padding-box`; basic shapes animate through `clipPath` in `data-hf-keyframes` for iris, diamond, and unfold reveals) and fade them with a gradient `mask-image`; see `examples/clip-mask.html`. For line art, put `data-hf-draw` (with `-at`, `-duration`, `-stagger`, `-easing`) on an inline `<svg>` so its strokes draw themselves, and move any element along a curve with `data-hf-motion-path="M0 0 C ..."` (`-rotate="auto"` turns it with the path); see `examples/vector-motion.html`. See `examples/effects.html` and `examples/filter-motion.html`.

CSS animation is limited to the documented transform, opacity, and timing-function subset. Static transforms support translation, scale (uniform or per axis), rotation, and skew, around `transform-origin`. Unsupported CSS and HTML return explicit errors; do not replace unsupported behavior with a browser-only implementation and claim the native renderer supports it.

## Assets and audio

Use relative paths to local PNG, JPEG, WebP, or SVG images. SVG (file or inline `<svg>`) needs an explicit width and height, is rasterized at the target size, and must be static: no `<text>`, SMIL, scripts, `<foreignObject>`, or external references. `<audio>` supports local WAV, FLAC, Ogg Vorbis, and MP3 sources, with documented timing, trim, loop, volume, and fades. Audio mixing uses the native encoder; `--encoder ffmpeg` rejects compositions containing `<audio>`. Keep the checked audio peak at or below 1.0 to avoid clamping.

For slow motion, fast forward, or speed ramps on `<video>` or `<audio>`, use `data-hf-speed="0.5"` (0.05 to 16) or `data-hf-speed-ramp='[{"at":0,"speed":1},{"at":1,"speed":0.25,"easing":"ease-in-out-cubic"}]'` (rates 0 to 16, `at` from the clip start, strictly increasing; at least one keyframe must have a nonzero speed, so an all-zero ramp is rejected even with `data-duration`; a ramp ending at 0 freezes and needs `data-duration`). `data-media-start` and `data-hf-trim-start` are source-time offsets (2 skips two source seconds at any speed); `data-duration` and fades are clip time, never the `playbackRate` property. A video's sound follows its picture; pitch follows the rate. Smooth slow motion needs a high-frame-rate source because frames repeat rather than interpolate. Check `videos[].speed`/`mediaEnd` and `audio.clips[].mediaSeconds`, then snapshot the start, the slowest point, and the end of the ramp. See `examples/speed.html`.

For a mix with voice and music, put the effects on the clips: `data-hf-eq="voice"` on the voice, and on the music `data-hf-eq="music-bed"` plus `data-hf-duck="<voice id>"` (12 dB by default; tune `data-hf-duck-amount`, `-threshold` in dBFS, and the look-ahead `-attack`, `-hold`, and `-release` in seconds). Automate level changes with `data-hf-volume-ramp='[{"at":0,"volume":1},{"at":7,"volume":1},{"at":8,"db":-60,"easing":"ease-in-cubic"}]'` (keyframes in clip seconds, `volume` 0 to 8 or `db`, multiplied with `data-volume` and the fades). EQ JSON bands are `{type, freq, gain, q}` with types `highpass`, `lowpass`, `bandpass`, `notch`, `peak`, `lowshelf`, `highshelf`; `gain` (dB) is required on `peak`, `lowshelf`, and `highshelf`, and must be omitted on `highpass`, `lowpass`, `bandpass`, and `notch`. Each trigger needs an `id`. In the `check` report, compare `audio.clips[].effects.duck.regions` with the speech times, read `eq.responseDb`, and keep `audio.peak` at or below 1.0. See `examples/audio-effects.html`.

## Cinematic layers

- Number transparent PNG or WebP cels consecutively in a local directory. Use `<img data-hf-sequence="assets/frame_{frame:04}.png" data-hf-sequence-first="1" data-hf-sequence-fps="12" data-hf-sequence-playback="loop">` with an explicit box and without `src`. Defaults are first 0, 12 fps, and hold. `pingpong` reverses without repeated endpoint cels. Frame numbers are sampled from clip-local time.
- Put `data-hf-parallax` (0–8, default 1) on a direct camera child. Zero cancels camera pan on that plane while preserving zoom. Values above 1 amplify pan. Keep moving artwork large enough to cover the edges.
- For generative imagery, `data-hf-shader="<program>"` on a sized non-root `<div>` (no text of its own; children draw on top) evaluates an expression program per pixel: `let` bindings, then a final `rgb(...)`/`rgba(...)`; inputs `uv`, `px`, `size`, `aspect`, `t`; functions include `mix`, `smoothstep`, `noise`, `fbm`, `voronoi`, `hash`, `palette`, `hsv`, `grain`, and `vignette`. Options: `data-hf-shader-uniforms` (JSON numbers, arrays, or CSS colors with `var()`), `data-hf-shader-keyframes` (animated uniforms), `data-hf-shader-resolution` (`1`, `0.5`, `0.25`), `data-hf-shader-dither` (`on`/`off`). See `docs/shaders.md` and the `aether-motion-shaders` skill.
- For real geometry, use `data-hf-3d` on a sized non-root `<div>` clip (optional `data-hf-3d-antialias` 1 to 4, default 2) holding only `<hf-node>`, `<hf-mesh shape="plane|box|pyramid|cone|cylinder|sphere|custom">`, `<hf-light type="ambient|directional">`, and one `<hf-camera>` (each closed explicitly). Axes are x right, y down (up is -y), z toward the viewer, origin at the box center; nodes take `position`, `rotation="rotateX rotateY rotate"`, `scale`, and `data-hf-keyframes` (`x`, `y`, `z`, `rotateX`, `rotateY`, `rotate`, `scale`; the camera uses `x`, `y`, `z`, `yaw`, `pitch`, `roll`, `zoom`; lights add `intensity`). Meshes take `color`, `material="lambert|unlit"`, `cull="back|none"`; the camera takes `perspective` or `fov`, `projection="orthographic"`, `target="#id|x y z"`, `near`, `far`. No textures, PBR, shadows, point lights, model files, or skeletal animation. See `docs/3d.md` and the `aether-motion-3d` skill.
- For true depth, use `data-hf-space="perspective|orthographic"` on a non-root container (a perspective space takes `data-hf-perspective`, default 1000 px; an orthographic one rejects it). Its children are planes: `data-hf-z` (px, toward the viewer), `data-hf-rotate-x`, `data-hf-rotate-y` (degrees), `data-hf-backface="hidden"`, keyframed as `z`, `rotateX`, `rotateY`; nested planes inherit their parent's 3D transform. `data-hf-camera` or `data-hf-shots` on the space take `x`, `y`, `zoom`, `z` (dolly), `rotateX` (tilt), `rotateY` (pan), and `rotate` (roll), and `data-hf-camera-subject` follows a subject in depth (not with a camera that turns, and not inside a nested or flattening space). Planes are ordered exactly (intersecting planes are split) and clip near the camera; nested spaces, parallax children, per-plane motion blur, and planes under `overflow: hidden` or filters (flattened into them) all work.
- To follow a character, put `data-hf-camera-subject="<id>"` on the camera (with `data-hf-camera-anchor="x y"` for where it sits, and equal `-lag` and `-lookahead`, about 0.3 to 0.5 s, for steady framing of a stepped walk). Compose camera moves with `data-hf-shots` presets (`static`, `follow`, `pan`, `dolly-in`, `dolly-out`, `reveal`) instead of hand-timed keyframes; shots share one continuous camera with the `smooth` easing. Use `"easing":"smooth"` in `data-hf-camera` keyframes for continuous velocity. Keep scene changes as clips with `data-hf-transition`, never as shots. Check the `cameras` entry of `check` and snapshot the start, middle, and end of every shot; leave overscan for the widest zoom and the farthest pan of each plane (`k * focus`).
- Root `data-hf-exposure` (-4 to +4 stops), `data-hf-highlight-rolloff` (0–1), and `data-hf-shadow-toe` (0–1) are optional. They apply after the root CSS grade and before vignette and grain. Use `data-hf-bloom` on the individual light source and pass the export FPS when reviewing frame-based stills.

## External scenes

Place an empty `div`, `section`, `article`, or `main` directly inside a composition root. Set a unique `id`, relative HTML `data-composition-src`, `data-start`, and `data-track-index`. Set `data-duration` to cut the source shorter, or omit it to use the source duration. Set `data-variable-values` to a JSON object of the source's declared variable IDs and values. Match canvas dimensions or set `data-composition-fit` (`contain`, `cover`, or `none`; `fill` is an error), resolve assets relative to the file that uses them, and reference the host ID for transitions between files. Keep cameras inside the source root and composition-wide finishing on the outer root. Nesting supports eight levels and 256 instances (reused instances count each time), and the flattened tree at most 200,000 elements. Repeating an instance is cheap: the scene compiles once per set of values and its instances share the compiled elements and text rasters. An opaque full-frame scene (solid root background, fully opaque, unmoved, no host filter, blend, mask, or clip) hides what is drawn before it, which is then skipped. `check` lists every file read under `dependencies`, and `preview --watch` re-renders when any of them changes (or a missing file appears), recompiling only the scenes whose files changed and the scenes that import them. Validate the assembled composition and snapshot both sides of each cut.
